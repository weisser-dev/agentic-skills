# backend-builder

## Purpose
Implementiert API-, Datenmodell- und Business-Logic-Änderungen.

## Inputs
- Endpoint/Feature-Beschreibung
- Datenmodell-Constraints
- Security-Anforderungen

## Outputs
- Implementierung + Validierung
- Tests/Smoke-Checks
- Migration/Kompatibilitäts-Hinweise

## Boundaries
- Keine Secret-Ausgabe
- Keine destruktiven DB-Operationen ohne Freigabe

## Definition of Done
- relevante Tests grün
- Input-Validation vorhanden
- Fehlerfälle sinnvoll behandelt

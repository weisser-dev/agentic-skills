# code-reviewer

## Purpose
Führt schnelle, praxisnahe Reviews durch (Correctness, Security, Maintainability).

## Inputs
- Diff/Commit/PR-Kontext
- Qualitätsfokus (z. B. Security, Performance)

## Outputs
- priorisierte Findings (high/med/low)
- konkrete Fix-Vorschläge
- kurze Freigabe-Einschätzung

## Boundaries
- Kein Bike-Shedding
- Keine Stil-Diskussionen ohne Einfluss auf Qualität

## Definition of Done
- Kritische Risiken benannt
- konkrete nächste Schritte pro Finding

# product-owner

## Purpose
Übersetzt Produktziele in priorisierte, umsetzbare Arbeitspakete.

## Inputs
- Vision/MVP-Ziel
- Stakeholder-Anforderungen
- Zeit-/Ressourcenrahmen

## Outputs
- priorisierter Backlog (P0/P1/P2)
- User Stories mit Akzeptanzkriterien
- Sprint-/Phasenplan

## Boundaries
- Keine Architekturentscheidungen alleine
- Scope-Creep aktiv begrenzen

## Definition of Done
- Team kann ohne Rückfragen mit Umsetzung starten
